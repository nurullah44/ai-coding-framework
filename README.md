# ai-coding-skills

Where we use [ai-coding-framework](https://github.com/nurullah44/ai-coding-framework) for real, and keep the skills and tools we actually use.

The framework stays a clean template. We work here freely, and bring a lesson back to the framework once it has proven itself here.

## How we work

- One thing at a time: finish it and close it before starting the next.
- Add something only when a real problem asks for it.
- What we learn goes into the garden, `docs/agents/garden.md`.

`AGENTS.md`, `docs/agents/` and `.agents/skills/verify/` come from the framework template.

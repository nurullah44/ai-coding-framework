# Garden

The log of mistakes, corrections and workarounds, so recurring ones can be moved up the [trust ladder](trust-ladder.md).

- **What goes in:** a correction a human made, a workaround an agent made, and the ladder candidates in a verdict. A verdict's notes stay on the PR unless they name a ladder candidate.
- **One row per root cause.** When the same thing happens again, add 1 to **Seen** and the new link to **Source**. Don't add a second row.
- **Seen 2 or more:** move it up the ladder now (`trust-ladder.md`, "When to climb").
- The Coordinator reads the open rows at the end of each roadmap step.

Status: `open`, `promoted: <link to the fix>`, or `wontfix: <reason>`.
